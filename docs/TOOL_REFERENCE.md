# GitNexus + CGC — Combined Tool Reference

## MCP Config Generation

MCP server configs are generated by `config_gen.py` — never write them manually:

```bash
uv run python src/config_gen.py --detect --project-path .          # auto-detect + generate
uv run python src/config_gen.py --platform cursor --print           # preview for a platform
```

See `docs/MCP_CONFIGS.md` for the full 10-platform reference.

## GitNexus MCP Tools (7 tools)

| Tool | Purpose | Example |
|------|---------|---------|
| `query` | Find execution flows by concept | `gitnexus_query({query: "auth middleware"})` |
| `context` | 360-degree symbol view | `gitnexus_context({name: "validateUser"})` |
| `impact` | Blast radius / what breaks | `gitnexus_impact({target: "fnName", direction: "upstream"})` |
| `detect_changes` | Git diff impact analysis | `gitnexus_detect_changes()` |
| `rename` | Safe graph-assisted rename | `gitnexus_rename({target: "old", newName: "new"})` |
| `cypher` | Raw graph queries | `gitnexus_cypher({query: "MATCH ..."})` |
| `list_repos` | List indexed repos | `gitnexus_list_repos()` |

## GitNexus CLI

```bash
npx gitnexus analyze [--force] [--embeddings] [--skills]  # Build/refresh index
npx gitnexus status                                        # Check freshness
npx gitnexus clean [--force] [--all]                       # Delete index
npx gitnexus wiki [--force] [--gist]                       # Generate docs
npx gitnexus list                                          # List indexed repos
```

## CGC CLI

```bash
uv run cgc index <path> [--force]              # Index a project
uv run cgc stats <path>                        # Show index stats
uv run cgc watch <path>                        # Live file watcher
uv run cgc find name "term"                    # Search by name
uv run cgc find pattern "regex"                # Search by regex
uv run cgc find content "concept"              # Fuzzy content search
uv run cgc analyze callers "function"          # Who calls this?
uv run cgc analyze callees "function"          # What does this call?
uv run cgc analyze imports "module"            # Who imports this?
uv run cgc analyze inheritance "Class"         # Class hierarchy
uv run cgc analyze dead-code                   # Find unused code
uv run cgc analyze complexity                  # Complexity hotspots
uv run cgc query "CYPHER_QUERY"                # Raw Cypher query
uv run cgc visualize                           # Start viz server
```

## Pre-Commit Checklist

Before every commit:
1. `npx gitnexus status` — index fresh?
2. `gitnexus_detect_changes()` — what did I change?
3. `gitnexus_impact()` on each changed symbol — blast radius
4. `uv run cgc stats <project>` — CGC index fresh?
